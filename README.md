# FarmDrop Sauces 🌿

FarmDrop Sauces is a website project created to showcase a sauce brand and its different products. The main idea behind this project is to build a simple, attractive, and user-friendly website where customers can explore different sauce flavours and learn more about the brand.

## About the Project

This project was developed using HTML, CSS, and JavaScript. I focused on creating a clean design, displaying products properly, and adding interactive features to make the website easy to use.

## Features

- Attractive homepage
- About section
- Different sauce products and flavours
- Why Choose Us section
- Customer testimonials
- Contact form
- Newsletter section
- Responsive navigation
- Smooth scrolling and animations

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
- Vercel

## How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/harshilchugh2007-dot/Farm-Drop-Sauces.git
```

2. Open the project folder.
3. Open `index.html` in your browser.
4. You can also use VS Code with the Live Server extension.
